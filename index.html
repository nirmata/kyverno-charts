Install

Add the repository, then install the charts you need.

# Add the Nirmata chart repository
helm repo add nirmata https://nirmata.github.io/kyverno-charts/
helm repo update

# Enterprise Kyverno
helm install kyverno nirmata/kyverno -n kyverno --create-namespace

# Notation adapter (AWS Signer)
helm install kyverno-notation-aws nirmata/kyverno-notation-aws -n kyverno-notation-aws --create-namespace

# Kube-bench adapter (CIS benchmark reports)
helm install kube-bench-adapter nirmata/kube-bench-adapter -n kube-bench --create-namespace
💡 A Nirmata license is required to pull N4K images. Request access or email support@nirmata.com.
